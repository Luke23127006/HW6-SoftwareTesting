# [BUG-005] Admin coupon creation accepts an expired administrator JWT

## Requirement

- `FR-12`: admin-only operations require authenticated administrator access.
- `SEC-02`: security-sensitive APIs require a valid JWT.

## Environment

- Backend: EShop Node/SQLite SUT in GitHub Actions
- Endpoint: `POST /api/admin/coupons`
- Commit: `34ea594f39061e6eed9c8be9a702141f20109b96`

## Preconditions

- An expired JWT representing the administrator is available.
- The coupon code is otherwise valid and unique.

## Steps to Reproduce

1. Start the seeded backend.
2. Send a valid coupon-creation body with `Authorization: Bearer <expired-admin-token>`.
3. Inspect the response and created coupon.

## Expected Result

The expired token is rejected and no coupon is created.

## Actual Result

The SUT returned HTTP 200 with `{"message":"Coupon created","id":7}`.
