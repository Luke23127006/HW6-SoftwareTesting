# [BUG-003] Apply Coupon accepts missing, malformed, and expired JWTs

## Requirement

- `FR-09 C4`: user must have a valid JWT.
- `SEC-02`: security-sensitive APIs require a valid JWT.

## Environment

- Backend: local EShop Node/SQLite SUT
- Base URL: `http://localhost:3000`
- Commit: a674794

## Preconditions

- Active eligible `SAVE10` coupon.

## Steps to Reproduce

1. Call `POST /api/apply-coupon` without `Authorization`.
2. Repeat with `Authorization: Bearer not-a-jwt`.
3. Repeat with an expired JWT.
4. Inspect each response.

## Expected Result

Each request is rejected and no discount is applied.

## Actual Result

All three requests returned HTTP 200 and applied the coupon.
