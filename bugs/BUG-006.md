# [BUG-006] Admin coupon creation accepts null and invalid coupon types

## Requirement

- `FR-17`: `type` is required and must be `percent` or `fixed`.

## Environment

- Backend: EShop Node/SQLite SUT in GitHub Actions
- Endpoint: `POST /api/admin/coupons`
- Commit: `34ea594f39061e6eed9c8be9a702141f20109b96`
- Authentication: valid administrator JWT

## Preconditions

- The administrator is authenticated.
- Each request uses an otherwise valid, unique coupon code.

## Steps to Reproduce

1. Send a coupon-creation request with `type: null`.
2. Repeat with a value outside the allowed `percent` and `fixed` enum.
3. Inspect each response.

## Expected Result

Each request is rejected and no coupon is created.

## Actual Result

Both requests returned HTTP 200 and created coupons.
