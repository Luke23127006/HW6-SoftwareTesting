# [BUG-004] Admin coupon creation accepts missing required fields

## Requirement

- `FR-17`: `code`, `type`, `discount_value`, `expired_at`, `min_order_amount`, and `max_uses_per_user` are required.

## Environment

- Backend: local EShop Node/SQLite SUT
- Base URL: `http://localhost:3000`
- Authentication: valid admin JWT
- Commit: a674794

## Preconditions

- Valid admin token.

## Steps to Reproduce

1. Send `POST /api/admin/coupons` without `code` but with the other fields.
2. Repeat with each of the other required fields `type`, `min_order_amount`, and `expired_at` omitted.
3. Send the endpoint an empty JSON body.
4. Inspect the responses and created IDs.

## Expected Result

Each request is rejected and no coupon row is created.

## Actual Result

The requests returned HTTP 200 and created coupons. The original local run demonstrated missing `code` and an empty body; CI run `33228816770` additionally demonstrated acceptance of missing `type`, `min_order_amount`, and `expired_at`.
