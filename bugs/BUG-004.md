# [BUG-004] Admin coupon creation accepts missing required fields

## Requirement

- `FR-17`: `code`, `type`, `discount_value`, `expired_at`, `min_order_amount`, and `max_uses_per_user` are required.

## Environment

- Backend: local EShop Node/SQLite SUT
- Base URL: `http://localhost:3000`
- Authentication: valid admin JWT
- Commit: a674794

## Preconditions

- Valid admin token.

## Steps to Reproduce

1. Send `POST /api/admin/coupons` without `code` but with the other fields.
2. Send the endpoint an empty JSON body.
3. Inspect responses and created IDs.

## Expected Result

Both requests are rejected and no coupon row is created.

## Actual Result

Both returned HTTP 200 and created coupons; the real run returned IDs 43 and 45.
