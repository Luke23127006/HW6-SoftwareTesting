# [BUG-007] Admin coupon creation accepts numeric values outside FR-17 constraints

## Requirement

- `FR-17`: `discount_value > 0`.
- `FR-17`: `min_order_amount >= 0`.
- `FR-17`: `max_uses_per_user >= 1`.

## Environment

- Backend: EShop Node/SQLite SUT in GitHub Actions
- Endpoint: `POST /api/admin/coupons`
- Commit: `34ea594f39061e6eed9c8be9a702141f20109b96`
- Authentication: valid administrator JWT

## Preconditions

- The administrator is authenticated.
- Each request uses an otherwise valid, unique coupon code.

## Steps to Reproduce

1. Send coupon-creation requests with `discount_value` equal to zero and below zero.
2. Send a request with `min_order_amount` below zero.
3. Send requests with `max_uses_per_user` equal to zero and below zero.
4. Inspect each response.

## Expected Result

Each constraint-violating request is rejected and no coupon is created.

## Actual Result

All five requests returned HTTP 200 and created coupons.
