# [BUG-001] Percent coupon calculation uses the wrong formula

## Requirement

- `FR-09`: `discount_amount = total × discount_value / 100`; `final_amount = total - discount_amount`.

## Environment

- Backend: local EShop Node/SQLite SUT
- Base URL: `http://localhost:3000`
- Student ID header: `23127006`
- Commit: a674794

## Preconditions

- Seeded active `SAVE10` coupon: percent 10, minimum 300000.
- Request total exceeds the minimum.

## Steps to Reproduce

1. Start the seeded backend.
2. Send `POST /api/apply-coupon` with `{"code":"SAVE10","total_amount":500000,"user_id":1}`.
3. Inspect `discount_amount` and `final_amount`.

## Expected Result

`discount_amount = 50000` and `final_amount = 450000`.

## Actual Result

HTTP 200 returned `discount_amount = -4500000` and `final_amount = 5000000`. A second test at total 1000000 returned `-9000000` and `10000000` instead of `100000` and `900000`.
