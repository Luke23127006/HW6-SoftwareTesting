# [BUG-002] Coupon is rejected when total equals the minimum threshold

## Requirement

- `FR-09 C3`: `total_amount >= min_order_amount` is eligible.

## Environment

- Backend: local EShop Node/SQLite SUT
- Base URL: `http://localhost:3000`
- Commit: a674794

## Preconditions

- Active unexpired `SAVE10` coupon with minimum 300000.

## Steps to Reproduce

1. Send `POST /api/apply-coupon` with `{"code":"SAVE10","total_amount":300000,"user_id":1}`.
2. Inspect the response.

## Expected Result

The coupon is eligible at the inclusive minimum; expected formula values are discount 30000 and final 270000.

## Actual Result

The SUT returned HTTP 400 and did not return discount values.
