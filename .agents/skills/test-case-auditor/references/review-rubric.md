# Human Audit Rubric

## VALID

The case is meaningful, feasible, non-duplicate, traceable, and its expected behavior is supported by the supplied sources.

## INVALID

Use when the test is fundamentally wrong, contradictory, impossible, irrelevant, or duplicated without purpose.

## INCOMPLETE

Use when the scenario is useful but important preconditions, assertions, setup/cleanup, expected behavior, or traceability are missing.

## Correction Rule

Every INVALID or INCOMPLETE case must preserve the original AI output and record the student's precise correction.
